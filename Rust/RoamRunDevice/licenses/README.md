Licenses of crates that are packaged without one, read by `scripts/third-party-licenses.py`
(`<crate name>.txt`).

- `idevice.txt`: `LICENSE.txt` from its repository.
- `ns-keyed-archive.txt`, `plist-macro.txt`: neither the crate nor its repository carries a
  text. This is the MIT license (which each names in its `Cargo.toml`) with the author named
  there. Replace it with theirs if they publish one.
