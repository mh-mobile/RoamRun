Licenses of crates that are packaged without one, read by `scripts/third-party-licenses.py`
(`<crate name>.txt`).

- `idevice.txt`, `ns-keyed-archive.txt`, `plist-macro.txt`: as in `Rust/RoamRunDevice/licenses`.
- `roamrun-device.txt`: this repository's own `LICENSE`.
- `age.txt`, `age-core.txt`: `LICENSE-MIT` of str4d/rage.
- `bech32.txt`: `LICENSE-MIT` of rust-bitcoin/rust-bech32.
- `cookie-factory.txt`: `LICENSES/MIT.txt` of rust-bakery/cookie-factory.
- `fluent-langneg.txt`: `LICENSE-MIT` of projectfluent/fluent-langneg-rs.
- `intl_pluralrules.txt`: `intl_pluralrules/LICENSE-MIT` of zbraniecki/pluralrules.
- `r-efi.txt`: the crate's own `AUTHORS` file, which holds its license texts.
- `io_tee.txt`: neither the crate nor its repository carries a text. This is the MIT license
  (one of the two its README names) with the repository's owner named. Replace it with theirs
  if they publish one.
